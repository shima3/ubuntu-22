#### # 目的
ラムダ計算の学習者が、入力したラムダ式が「アルファ正規化」される過程を視覚的に理解するためのWebツールを作成します。このツールは、サーバーサイドの処理を必要とせず、ブラウザだけで完結するものとします。

#### # 機能要件
1.  **入力機能**
    * ユーザーがラムダ計算の式を入力できるテキストエリアを設置してください。
    * ラムダの記法として `λx.M` と `\x.M` の両方をサポートしてください。
    * 以下の省略記法を正しく解釈できるようにしてください。
        * **複数の引数**: `λx y.M` は `λx.(λy.M)` として解釈してください。
        * **左結合の適用**: `M N P` は `((M N) P)` として解釈してください。

2.  **処理機能**
    * 入力されたラムダ式を**アルファ正規化**してください。
    * アルファ正規化とは、束縛変数（ラムダによって束縛される変数）の名前を、式の意味を変えずに一貫した規則でリネームすることです。例えば、`v0`, `v1`, `v2`, ... のように出現順に命名してください。
    * 自由変数（どのラムダにも束縛されていない変数）の名前は変更しないでください。
    * **重要:** **ベータ簡約（式の評価や計算）は行わないでください。** このツールの目的はアルファ正規化のみです。

3.  **出力機能**
    * 正規化されたラムダ式を、以下の2つの形式で表示してください。
        * **1. 略記なし（完全な括弧付け）**: 式の構造が曖昧さなく理解できるよう、すべての適用とラムダ抽象を括弧で囲んだ形式です。
            * 例: `(((λv0.(λv1.v0)) (λv2.v2)) a)`
        * **2. 略記あり**: 一般的なラムダ計算の記述ルール（後述）に従い、不要な括弧を省略した読みやすい形式です。

#### # 技術要件
* 完成品は、**単一のHTMLファイル**として提供してください。
* CSSとJavaScriptは、HTMLファイル内に `<style>` タグと `<script>` タグを使って直接記述してください。
* 外部のJavaScriptライブラリやフレームワーク（jQueryなど）は使用しないでください。
* ユーザーが入力した式の構文が不正な場合は、エラーメッセージを表示する機能を実装してください。

#### # UI/UX要件
* ページの構成は、上から「タイトルと説明」「入力テキストエリア」「実行ボタン」「結果表示エリア」の順でシンプルに配置してください。
* 結果表示エリアは、「略記なし」と「略記あり」の2つのセクションに分けてください。
* 各結果表示エリアの右上に、表示されている内容をクリップボードにコピーできる「コピー」ボタンを設置してください。ボタンをクリックしたら、成功したことがユーザーにわかるように一時的にボタンの表示を変更するなどのフィードバックを加えてください。

#### # ラムダ計算の記述ルール
1. **ラムダ抽象 (`λx.M`)**
* 抽象は **式全体の最後まで作用する** とみなします。
  つまり
  ```
  λx. M N
  ```
  は
  ```
  λx.(M N)
  ```
  を意味します。

* 複数の抽象は続けて書けます。
  ```
  λx y z. M
  ```
  は
  ```
  λx.(λy.(λz.M)))
  ```
  を意味します。

2. **関数適用 (`M N`)**
* 適用は **左結合**。
  ```
  M N P
  ```
  は
  ```
  ((M N) P)
  ```
  を意味します。

3. **カッコが必要なとき**
以下の2つの場合だけ **カッコ必須**：

* 抽象が適用の一部に現れるとき
   ```
   (λx.x) y
   ```
   のように、ラムダ抽象が関数または引数になるときはカッコで囲む。
   例: `λf.f (λx.x)` ← これは `λf.(f (λx.x))` を意味。

* 明示的にグルーピングを変えたいとき
   ```
   (M N) P
   ```
   と
   ```
   M (N P)
   ```
   は別物なので、右に寄せたい場合はカッコ必須。

4. **具体例**

* 完全括弧付け:
  ```
  (((λv0.(λv1.v0)) (λv2.v2)) a)
  ```
  略記あり:
  ```
  (λv0 v1.v0) (λv2.v2) a
  ```
  → ここでは `(λv0 v1.v0)` と `(λv2.v2)` が適用に登場するので両方カッコ必須。

* 完全括弧付け:
  ```
  (λv0.(λv1.((v0 (λv2.v2)) a)))
  ```
  略記あり:
  ```
  λv0 v1.v0 (λv2.v2) a
  ```
  → 外側が抽象なのでカッコ不要。適用の右側 `(λv2.v2)` は抽象なのでカッコ必須。

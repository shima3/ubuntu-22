ラムダ計算アルファ正規化ツール

ラムダ式をアルファ正規化するツールです。

このツールは、入力されたラムダ式の束縛変数を左から右への出現順に v0, v1, ... と名前を付け直します。ただし、自由変数は名前を保持します。このため、v0, v1, ... という名前の自由変数があると正しく正規化できない場合があります。
  • アルファ正規化とは、アルファ等価なラムダ式を同じ形に統一するようにアルファ変換することです。
  • アルファ等価とは、束縛変数の名前が違うだけで関数としての働きが同じという意味です。
  • アルファ変換とは、元のラムダ式とアルファ等価な別のラムダ式を求めることです。
  • アルファ正規化したラムダ式はベータ変換やイータ変換も必要となる正規形とは異なります。
  • 変数のシャドーイングとは、外側と内側で同じ名前の変数を宣言したとき、内側では内側の変数が優先し、外側の変数は参照できなくなることです。
入力規則:
  • ラムダは λ または \ で書けます。
  • 複数引数は λx y.M のように書けます。
  • 適用は左結合、M N P = ((M N) P) です。
  • 自由変数の名前に v0, v1, ... は使わないでください。

入力例: (クリックで入力欄に挿入)

  • 恒等関数: λx.x
  • 高階関数: \f x.f (f x)
  • 適用（括弧あり）: (λx y.x) (λz.z) a
  • 適用（括弧なし）: \x y.x (\z.z) a
  • 変数のシャドーイング: λx.(λx.x) x
  • 複雑な適用: (\x y.x) (\z.z) a
